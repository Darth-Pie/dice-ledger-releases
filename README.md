# Dice Ledger releases

Downloads for Dice Ledger, a Foundry VTT v13 module that records every roll at the table and turns each
session into stats, awards, rivalries, notable moments and an end-of-session slideshow. dnd5e 5.x is
recommended.

## Install

In Foundry's Setup screen, open **Add-on Modules > Install Module**, paste this manifest URL and press
**Install**:

```
https://github.com/Darth-Pie/dice-ledger-releases/releases/latest/download/module.json
```

Then launch your world as GM and tick **Dice Ledger** under Game Settings > Manage Modules. New versions
appear in Foundry with an **Update** button. Players install nothing.

Each [release](https://github.com/Darth-Pie/dice-ledger-releases/releases) also carries `dice-ledger.zip`
for installing by hand: extract it into a `Data/modules/dice-ledger` folder so that `module.json` sits
directly inside it.

This repository holds release files only.
